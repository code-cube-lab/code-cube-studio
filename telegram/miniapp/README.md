# Code Cube Mini App

Статическая Mini App собирает первичный бриф и открывает диалог с `@wise_video` с готовым сообщением.

## Проверка

Откройте `index.html` через локальный HTTP-сервер. В обычном браузере используется явный preview-режим. В Telegram интерфейс получает тему через `telegram-web-app.js`.

Для запуска через BotFather нужен публичный HTTPS-URL. Mini App не использует `initDataUnsafe` для авторизации и не выдаёт платный доступ. Если позже появятся личный кабинет, оплата или защищённые данные, raw `initData` нужно проверять на backend.
