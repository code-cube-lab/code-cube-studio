# Code Cube Portfolio Bot

Бот показывает услуги, цены, портфолио и открывает Mini App для короткого брифа.

## Команды

- `/start` — старт и основные действия;
- `/services` — направления работы;
- `/prices` — стартовый прайс;
- `/brief` — запуск Mini App;
- `/help` — помощь;
- `/terms` — условия оценки;
- `/support` — связь с Олегом.

## Запуск

1. Скопируйте `.env.example` в `.env` и заполните значения локально.
2. Загрузите переменные окружения средствами вашего хостинга.
3. Выполните `npm run check`.
4. Запустите `npm start`.

Код использует long polling и встроенный `fetch` Node.js, поэтому внешние зависимости не нужны. Токен нельзя помещать в frontend, Git или скриншоты.

Для production предпочтительнее HTTPS webhook, журналирование, мониторинг и постоянное хранилище. Эта версия — безопасный стартовый контур и не считается Telegram‑verified, пока реально не запущена через BotFather.
