# Telegram-контур Code Cube

Пакет подготовлен для запуска канала, бота и Mini App вокруг портфолио Code Cube.

## Состав

- `channel-passport.md` — название, описание, рубрики, закреп и навигация.
- `launch-posts.md` — 15 готовых публикаций для старта.
- `content-calendar.md` — календарь на четыре недели и метрики.
- `bot/` — Telegram-бот без сторонних зависимостей.
- `miniapp/` — статическая Mini App для первичного брифа.

## Уровень готовности

- тексты и исходники: готовы;
- локальная Mini App: проверяется как обычный сайт;
- bot token: не включён и не должен попадать в Git;
- создание канала, BotFather и публикация постов: выполняются только в аккаунте владельца;
- Telegram runtime считается проверенным только после запуска через реального бота и HTTPS-URL.
