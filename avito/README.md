# Avito-пакет Code Cube

## Что готово

- `profile.md` — имя, специализация и текст профиля;
- `listing-site.md` — объявление о сайтах;
- `listing-telegram.md` — объявление о ботах и Mini Apps;
- `listing-channel.md` — объявление об упаковке Telegram-канала;
- `price-list.md` — точные позиции для прайс-листа;
- `images/` — пять кадров фото-воронки в SVG и PNG.

## Как размещать

1. Указать свой реальный город или выбрать дистанционное оказание услуги.
2. Не добавлять несуществующий стаж, дипломы, отзывы и число клиентов.
3. Выбрать одну точную цену из прайса, а не `1 ₽`.
4. Загрузить кадры `01`–`05` в указанном порядке.
5. Использовать призыв «Напишите в чат Авито» без внешней ссылки.
6. После 7–14 дней сравнить просмотры, добавления в избранное, контакты и стоимость контакта.

Конкретные карточки продавцов Avito автоматически не проверялись: ограничение площадки не обходилось. Пакет опирается на открытые рыночные цены и официальный материал «Авито Услуг» о точной цене.
