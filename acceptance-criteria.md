# Acceptance criteria

## Структура и контент

- В проекте есть отдельные страницы: главная, услуги, кейсы, цены, процесс, контакты и политика.
- На каждой коммерческой странице есть один заметный переход к обсуждению проекта.
- В кейсах показаны четыре реальные публичные работы из рабочей среды, каждая с доступной ссылкой и без выдуманных метрик.
- На странице цен разделены рыночные диапазоны и собственный стартовый прайс.
- Ограничение прямого автоматизированного доступа к Avito отражено честно, а недоступные карточки продавцов не выдаются за проверенные.

## Навигация и доступность

- На каждой странице есть skip-link, логичный `h1`, семантическая навигация и видимый фокус.
- Меню работает с клавиатуры и на ширине телефона.
- Все изображения и декоративные элементы имеют корректное текстовое поведение.
- При `prefers-reduced-motion` интерфейс не зависит от анимации.

## Калькулятор

- Given посетитель открыл `pricing.html`, when он выбирает услуги, then сумма и диапазон обновляются без перезагрузки.
- Given ни одна услуга не выбрана, when отображается итог, then интерфейс просит выбрать хотя бы одно направление.
- Given услуги выбраны, when посетитель нажимает CTA, then открывается `t.me/wise_video` с подготовленным текстом и без автоматической отправки.

## Бриф

- Given посетитель открыл `contacts.html`, when он заполняет поля, then на странице появляется краткая сводка.
- Given обязательный тип проекта не выбран, when посетитель пытается продолжить, then видит понятное сообщение.
- Given бриф готов, when пользователь нажимает «Открыть Telegram», then данные передаются только в созданный Telegram URL по явному действию пользователя.

## Адаптивность

- На ширинах 390, 768, 1280 и 1440 пикселей отсутствует горизонтальный скролл.
- Кнопки не перекрываются фиксированными элементами и имеют удобную область нажатия.
- Крупные заголовки не обрезаются и не выходят за экран.
- Таблицы и тарифы читаемы на мобильном без масштабирования всей страницы.

## Техническая проверка

- Все внутренние ссылки возвращают существующие HTML-файлы.
- В консоли браузера нет необработанных ошибок.
- Базовый smoke-test открывает все страницы через локальный HTTP-сервер.
- JavaScript-калькулятор и генератор брифа проходят целевые проверки.
- В `qa-report.md` отдельно указаны уровни `structure`, `browser` и `production`; локальная проверка не называется публичным запуском.
