Прозрачность первой версии

Этот сайт не принимает оплату и не отправляет формы на сервер.

Калькулятор и бриф работают локально в браузере. Передача текста происходит только после вашего явного перехода в Telegram.

01 / CURRENT STATE

Что происходит сейчас

Минимум данных до появления реальной инфраструктуры.

Это техническое пояснение для стартовой локальной версии, а не финальная юридическая политика опубликованного бизнеса.

  • 01Калькулятор

    Выбор услуг и сумма рассчитываются в JavaScript и не сохраняются на сервере.

  • 02Бриф

    Заполненные поля используются только для предпросмотра и формирования Telegram-ссылки.

  • 03Telegram

    После клика открывается внешний сервис `t.me`. Дальнейшая обработка регулируется правилами Telegram.

  • 04Кейсы

    Ссылки ведут на внешние публичные сайты, у которых могут быть собственные правила и аналитика.

  • 05Шрифты

    Интерфейс может загружать публичные веб-шрифты Google Fonts; при недоступности используются системные шрифты.

02 / BEFORE RELEASE

Что добавить перед публикацией

Юридический текст должен соответствовать фактической инфраструктуре.

Нельзя заранее копировать универсальную политику, если ещё неизвестны домен, аналитика, CRM, хостинг и оператор данных.

Реквизиты

Указать фактического исполнителя, способы связи и применимые договорные условия.

Инфраструктура

Зафиксировать хостинг, аналитику, CRM, форму заявки, сроки хранения и права пользователя.

Согласие

Добавить явное согласие перед реальной отправкой формы, если сайт начнёт собирать персональные данные.
